# راهنمای سئو و عملکرد پاریسان

این راهنما وضعیت قابلیت‌های نسخه 0.16.0 افزونه Parisan Core را توضیح می‌دهد. این نسخه، پایهٔ اولیهٔ سئو و مرزبندی کش را فراهم می‌کند؛ به معنی تکمیل ابزار سئوی حرفه‌ای یا تضمین عملکرد CDN/Reverse Proxy نیست.

## تنظیمات سئو

از پیشخوان وردپرس وارد مسیر «متخصصان ← سئو و عملکرد» شوید. در این بخش می‌توانید توضیحات پیش‌فرض سایت، نام سالن، نشانی رسمی سایت و فعال/غیرفعال بودن Service JSON-LD را تنظیم کنید.

در ویرایش هر محتوای عمومی، جعبه «پیش‌نمایش و تنظیمات سئو» برای عنوان سئو و توضیحات متا در دسترس است. اگر عنوان یا توضیح اختصاصی خالی باشد، عنوان وردپرس و توضیح برگرفته از چکیده/متن یا توضیح پیش‌فرض استفاده می‌شود.

## خروجی‌های فعلی

- عنوان سند از سازوکار استاندارد WordPress و عنوان سفارشی پاریسان استفاده می‌کند.
- توضیحات متا با اولویت مقدار اختصاصی همان محتوا، چکیده و سپس توضیح پیش‌فرض ساخته می‌شود.
- Canonical و Open Graph برای صفحات عمومی تولید می‌شود.
- برای صفحه اختصاصی هر خدمت، داده ساختاریافته Service با ارائه‌دهنده از نوع BeautySalon تولید می‌شود.
- در صورت شناسایی Yoast SEO، Rank Math، SEOPress، All in One SEO یا The SEO Framework، خروجی متادیتای پاریسان کنار گذاشته می‌شود تا تداخل و تکرار کاهش یابد.
- نقشه سایت XML پایه از قابلیت هسته WordPress استفاده می‌کند؛ پاریسان هنوز نقشه سایت اختصاصی یا کنترل‌های پیشرفته آن را اضافه نکرده است.

## مرزبندی کش و حریم خصوصی

پاریسان درخواست‌های کاربران واردشده، صفحات دارای شورت‌کد رزرو، درخواست‌های دارای توکن مشتری و مسیر REST اختصاصی `/wp-json/parisan/v1/` را از کش عمومی مستثنا می‌کند. این درخواست‌ها با پرچم‌های سازگاری کش WordPress و هدرهای `private, no-store` علامت‌گذاری می‌شوند.

برای تغییر محتوای خدمات و متخصصان، رویداد `parisan_core_public_content_cache_invalidated` پس از پاک‌سازی کش شیء WordPress اجرا می‌شود تا اتصال‌دهندهٔ افزونه‌های کش بتواند صفحه‌ها و آرشیوهای وابسته را نیز پاک‌سازی کند.

## محدودیت‌ها و کارهای بعدی

- کنترل رابط کاربری robots/noindex، مدیریت Redirect و گزارش 404 هنوز تکمیل نشده‌اند.
- اتصال‌دهندهٔ اختصاصی برای LiteSpeed Cache، WP Rocket، W3 Total Cache یا CDN هنوز وجود ندارد.
- رفتار کش در Reverse Proxy/CDN واقعی و چندگرهی باید در محیط استقرار آزمایش شود.
- ابزار سنجش Core Web Vitals، گزارش سرعت، بودجه عملکرد و تست بار هنوز در دست توسعه‌اند.
- داده ساختاریافته فعلی فقط برای صفحات خدمت است؛ اطلاعات واقعی سالن، آدرس، تلفن، ساعات کار و قیمت‌ها باید پس از تعریف فیلدهای معتبر و تأیید مالک به schema افزوده شوند.
- فعال بودن یک افزونه سئو به‌تنهایی به معنی سازگاری کامل تمام نسخه‌ها و افزونه‌های جانبی نیست؛ خروجی واقعی باید در مرورگر و ابزارهای اعتبارسنجی بررسی شود.

## مرز ادعا

این قابلیت‌ها در کد افزونه پیاده‌سازی شده‌اند؛ تا زمان موفقیت CI روی commit نهایی و بررسی خروجی واقعی مرورگر، وضعیت نهایی آزمون و سازگاری محیط استقرار «تأییدنشده» است. این راهنما تضمین رتبه در موتور جست‌وجو، امتیاز Core Web Vitals یا عدم ذخیره داده در تمام لایه‌های زیرساختی را ادعا نمی‌کند.
