First-party salon operations foundation for the Parisan Beauty WordPress theme.

== Description ==

Parisan Core is the companion plugin for durable salon functionality. The initial foundation registers service and specialist content types. Booking transactions, customer records, schedules, messaging, and other operational features are not yet implemented in this version.

== Installation ==

1. Upload the paris an-core folder to the /wp-content/plugins/ directory (or install the packaged ZIP).
2. Activate Parisan Core from the WordPress Plugins screen.
3. Activate the Parisan Beauty theme.
