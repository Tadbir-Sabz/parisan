First-party salon operations foundation for the Parisan Beauty WordPress theme.

== Description ==

Parisan Core is the companion plugin for durable salon functionality. The initial foundation registers service and specialist content types, service pricing/duration metadata, service categories, specialist-to-service eligibility, and a weekly recurring availability editor. Date-specific schedule exceptions and booking transactions are not yet implemented.

== Installation ==

1. Upload the parisan-core folder to the /wp-content/plugins/ directory (or install the packaged ZIP).
2. Activate Parisan Core from the WordPress Plugins screen.
3. Activate the Parisan Beauty theme.
